📖 Pattern Documentation


            

                

                    
🎯 Two Pointers Pattern

                    
Uses two pointers to traverse data structures, often from opposite ends or at different speeds. Ideal for sorted arrays and linked lists.

                    
Common Problems: Two Sum, Palindrome Check, Container With Most Water

                    
Time Complexity: Usually O(n)

                    View LeetCode Problems →
                


                

                    
🪟 Sliding Window Pattern

                    
Maintains a window of elements and slides it across the data structure. Perfect for contiguous subarray/substring problems.

                    
Common Problems: Maximum Sum Subarray, Longest Substring Without Repeating

                    
Time Complexity: Usually O(n)

                    View LeetCode Problems →
                


                

                    
🐢🐇 Fast & Slow Pointers Pattern

                    
Uses two pointers moving at different speeds (Floyd's algorithm). Essential for cycle detection and finding middle elements.

                    
Common Problems: Linked List Cycle, Find Middle Node, Happy Number

                    
Time Complexity: Usually O(n)

                    View LeetCode Problems →
                


                

                    
🔍 Binary Search Pattern

                    
Divides search space in half repeatedly. Works on sorted data or when you can determine which half contains the answer.

                    
Common Problems: Search in Array, Find Peak Element, Search in Rotated Array

                    
Time Complexity: O(log n)

                    View LeetCode Problems →
                


                

                    
🔝 Top K Elements Pattern

                    
Uses heaps (priority queues) to efficiently find K largest/smallest elements or K most frequent items.

                    
Common Problems: Kth Largest Element, Top K Frequent Elements, K Closest Points

                    
Time Complexity: Usually O(n log k)

                    View LeetCode Problems →
                


                

                    
🌳 Tree BFS/DFS Pattern

                    
Traverses trees using Breadth-First Search (level-order) or Depth-First Search (in-order, pre-order, post-order).

                    
Common Problems: Level Order Traversal, Maximum Depth, Path Sum

                    
Time Complexity: O(n) where n is number of nodes

                    View LeetCode Problems →
                


                

                    
💎 Dynamic Programming Pattern

                    
Breaks problems into overlapping subproblems and stores results to avoid recomputation. Uses memoization or tabulation.

                    
Common Problems: Climbing Stairs, House Robber, Coin Change, Longest Common Subsequence

                    
Time Complexity: Varies, often O(n) to O(n²)
